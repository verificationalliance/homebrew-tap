# Open Source Verification Alliance tap

Homebrew casks from the [Open Source Verification Alliance](https://verificationalliance.org/).

```sh
brew install --cask verificationalliance/tap/osva-monitor
```

| Cask | What it is |
|---|---|
| `osva-monitor` | [OSVA Monitor](https://verificationalliance.org/app/): a macOS menu-bar app that checks what is installed against open-source vulnerability and malware data, with a Lean-proved core. Source: [verificationalliance/osva-monitor](https://github.com/verificationalliance/osva-monitor). |

The apps are signed with a Developer ID and notarized by Apple; each cask pins the release's SHA-256.
